# BUSINESS_GLOSSARY — Istilah

Dipakai supaya semua dokumen & agent memakai kata yang sama.

| Istilah | Arti |
|---|---|
| **Poin** | Satuan keanggotaan. Dipakai untuk menentukan peringkat, ditukar hadiah, atau dibayar sebagai leadership — tergantung jenisnya |
| **PA — Poin Affiliate** | Poin dari member baru yang disponsori langsung. Tidak bisa ditukar hadiah |
| **PR — Poin Reward** | Poin yang bisa ditukar hadiah. Didapat dari join, upgrade, dan RO |
| **PL — Poin Leadership** | Poin dari pertumbuhan jaringan bawah. Dibayar Rp 40.000/poin, bulanan |
| **Peringkat** | Reseller (1 poin) → Agent (3 poin) → Distributor (6 poin) → Manager (kualifikasi) |
| **Reseller / Agent / Distributor** | Nama sebutan untuk 1 / 3 / 6 poin. Bukan paket terpisah |
| **Manager** | Peringkat setelah Distributor. Syarat: Distributor + 20 poin dari orang yang diajak langsung |
| **Royal Manager (RM)** | Bukan peringkat baru. Sebutan untuk Manager yang punya Manager langsung di bawahnya. Dapat bonus tahunan |
| **Sponsor / pengajak / upline langsung** | Member yang mendaftarkan member baru |
| **Kode referral** | Username sponsor. Wajib diisi saat daftar |
| **Downline / jaringan bawah** | Semua member di bawah seseorang |
| **Upline / jaringan atas** | Rantai sponsor ke atas |
| **Selisih** | Bagian bonus yang diterima orang di atas = persen peringkatnya dikurangi persen yang sudah dibayar di bawahnya |
| **Compression** | Kalau peringkat di atasnya sama atau lebih rendah, dia dilewati dan bagiannya lanjut ke atas sampai ketemu peringkat lebih tinggi |
| **Bonus sponsor** | Bonus dari transaksi member baru, dibagi berantai pakai selisih. Cair harian |
| **Bonus leadership** | Rp 40.000/poin PL. Cair bulanan |
| **Bonus tahunan RM** | Rp 2.000/poin dari PL Manager langsung di bawahnya. Cair tahunan |
| **RO — Repeat Order** | Pembelian ulang. Rp 500.000/poin, dapat 1 poin pribadi + 1 poin sponsor, tanpa bonus uang |
| **Upgrade** | Naik peringkat dengan menambah poin, bayar selisihnya |
| **PIN** | Kode yang dikeluarkan admin setelah member transfer. Tanpa kedaluwarsa. Tiga jenis: registrasi, upgrade, RO |
| **Hangus** | Poin PL yang tidak pernah terbuka karena member tidak sampai Manager |
| **Kualifikasi** | Syarat yang harus dipenuhi untuk membuka hak (misal 20 poin untuk Manager) |
| **Tutup buku** | Tanggal pemotongan periode perhitungan bonus bulanan/tahunan |
| **Pencairan** | Proses menarik saldo bonus jadi uang |
| **Gate approval** | Titik di mana Owner harus menyetujui sebelum pekerjaan boleh lanjut |
| **Acceptance criteria** | Syarat yang harus terbukti terpenuhi sebelum tugas boleh dianggap selesai |
| **Bukti** | Perintah yang dijalankan + outputnya, atau file yang diubah. Bukan klaim |
